# Recursos de Ciberseguridad

## Herramientas de aprendizaje

### 🐉 Kali Linux
Distribución de Linux orientada a pruebas de seguridad informática y auditorías.

### 🦈 Wireshark
Herramienta utilizada para analizar y capturar tráfico de red.

### 🔎 Nmap
Herramienta para descubrimiento de redes, dispositivos y servicios.

### 🕷️ Burp Suite
Plataforma utilizada para realizar pruebas de seguridad en aplicaciones web.

### 🌐 Cisco Packet Tracer
Simulador de redes utilizado para practicar configuración y administración de dispositivos de red.

### 💻 Visual Studio Code
Editor de código utilizado para desarrollar proyectos y documentación técnica.

### 🐙 GitHub
Plataforma utilizada para almacenar, administrar y compartir proyectos mediante Git.

## Áreas de interés

- Seguridad de redes
- Seguridad web
- Análisis de vulnerabilidades
- Ethical Hacking
- Análisis de tráfico
- Seguridad de sistemas
- Modelado de amenazas
